# ⚡Поиск максимума в многопоточном режиме

Сравнение производительности однопоточного и многопоточного поиска максимального значения в слайсе из 10+ миллионов элементов.

## 🔧 Как работает

- Генерация случайного слайса заданного размера
- Поиск максимума в один поток
- Разделение слайса на 8 частей и параллельный поиск в горутинах
- Сравнение времени выполнения обоих подходов

## 🛠️ Стек

- Golang
- Стандартная библиотека (`math/rand`, `sync`, `time`)

## 🚀 Запуск

```bash
go run main.go
